# Xplora

The unofficial desktop application of XPL-HDMS instance licensed to Remedy Medical Services Private Limited

## Download

Download the latest version from the [Releases](https://github.com/Unofficial-Integrations/Xplora-Swing-Releases/releases) page.

## System Requirements

* Windows 10 or later 64-Bit editions only
* Linux support will be provided if there is requirement for it
* Internet connection for updates and application services

## Installation

1. Download the release.
2. Extract the installer.
3. Provide the password.
4. Run the application.

## Support

If you encounter a problem with XPLORA, please contact your organization's IT/support team.
